# 你好，我是 Leslieryin 👋

自动化专业在读。我喜欢用代码解决自己遇到的真实问题——这里的每个项目都始于「我自己需要这个」。

### 我在做什么

- 🎛️ **控制理论系列实验台**：[control-lab](https://github.com/Leslieryin/control-lab)（经典控制：二阶系统/PID/Bode/Nyquist/根轨迹）+ [modern-control-lab](https://github.com/Leslieryin/modern-control-lab)（现代控制：状态空间/能控能观/Ackermann 极点配置/观测器/卡尔曼滤波）——单文件网页版，拖滑块实时看曲线
- 🗺️ **自动化专业资源导航**：[awesome-automation-zh](https://github.com/Leslieryin/awesome-automation-zh)——控制理论 / 嵌入式 / 机器人 / 三大竞赛的开源资源点评 + 学习路径
- 📱 **开源二次开发**：为 [ArkPlots](https://github.com/ApodidaeDeSwift/ArkPlots)（明日方舟剧情管理工具）适配 Android 纯离线版（Capacitor，包体积 45MB→9MB），并向上游提交了安全加固 PR（更新包 SHA-256 校验、本地服务跨站防护）
- 🖼️ **AI 绘画**：ComfyUI 工作流搭建与教学，专注本地 GGUF 量化模型的显存友好方案
